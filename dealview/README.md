# dealview：freee の取引の表

ファームサイドの freee 会計の取引を、freee の取引一覧の画面に似せた表でチャットに出す部品。登録・変更の前の確認の表、登録・変更のあとの一覧、書き方を聞くときの過去の取引に使う（どの場面で何を出すかはスキル c03-deal-view に従う）。

今の版：`dealview/dv_v261126a.js`

```html
<div id="dv"></div>
<script src="https://cdn.jsdelivr.net/gh/sagawat/fs-claude-parts@main/dealview/dv_v261126a.js"></script>
<script>
(function g(){if(typeof DV!=='function')return setTimeout(g,100);DV({mode:'after',deals:[...],transfers:[...]})})();
</script>
```

## 1. 渡すもの

`DV(o)`。`o` の項目：

| 項目 | 中身 |
|---|---|
| `el` | 描く先（セレクタか要素。省くと `#dv`）。1つの返答に表を2つ出すときは `<div id="dv1">` などを分ける |
| `mode` | `plan`＝登録の前（期日はいつも時計の印、リンクなし）／`after`＝登録・変更のあと（金額を取引へのリンクに）／`change`＝変更の前（変える欄に 旧 → 新。リンクなし）／`past`＝過去の取引（リンクあり）。省くと `after` |
| `title` | 表の上の小さな題（省略可） |
| `deals` | 取引の配列（下の表） |
| `transfers` | 口座振替の配列（下の表）。取引の表の下に別の表で出す |
| `common` | 2行以上に共通する備考の後ろの部分。表の下に［共通］のチップを付けて1回だけ書く |
| `foot` | `false` で表の下の件数・合計を出さない |
| `theme` | `light`／`dark` で固定（見本を並べるときだけ。ふだんは省いて自動） |

取引（`deals` の1件）：

| 項目 | 中身 |
|---|---|
| `id` | freee の取引 ID（`after`・`past` で金額のリンクになる） |
| `kind` | `out`＝支出／`in`＝収入 |
| `date`・`due` | 発生日・期日（`YYYY-MM-DD`）。期日は発生日と違うときだけ印の下に出る |
| `done` | `true`＝決済済み（✓）／`false`＝未決済（時計） |
| `wallet` | 決済口座（未決済なら省く。「—」になる） |
| `desc` | 明細の取引内容（カードの印の行で、1行目の明細の下に出る） |
| `lines` | 明細の配列：`acct` 勘定科目・`amt` 金額・`tax` 税区分・`partner` 取引先・`item` 品目・`tags` メモタグの配列・`rmTags` 外すメモタグ（`change` で打ち消し線）・`memo` 備考・`common:true`（備考の後ろに［共通］） |

口座振替（`transfers` の1件）：`date`・`from`・`to`・`amt`・`memo`・`desc`・`url`（`after`・`past` で金額のリンク。freee の口座振替の URL が分かるときだけ）。

- `change` では、変える欄の値を `[旧, 新]` の配列で渡す（`amt`・`acct`・`tax`・`memo`・`partner`・`item`・`date`・`due`・`done`・`wallet`・`kind`、口座振替の `from`・`to`・`amt`）。旧は打ち消し線、新は矢印のあとに出る。合計は新の値で数える。
- 取引は発生日の新しい順に部品が並べ替える。合計は収入・支出に分けて部品が数える。
- 文字はすべて部品がエスケープする（HTML は渡せない）。

## 2. 見た目

- 列は freee の取引一覧に合わせる：収支／発生日／期日／勘定科目／金額・税区分／取引先・品目・メモタグ・備考・取引内容／決済口座。金額・税区分は右寄せ、中身の列だけが伸びる。1つの取引に明細が2行以上あれば、取引の中で縦に並べる。
- 口座振替は別の表（振替日／札「口座振替」／振替元／振替先／金額）。札は freee にない印で、取引の表と見分けるために置く。
- 幅の狭い画面（560px 以下）では見出しを消し、1取引を1枚に積む：1段目＝収支・発生日・期日の印・決済口座（右寄せ）、2段目から明細ごとに 勘定科目・税区分と右寄せの金額、その下にチップ・備考・取引内容。口座振替は 振替日・札・金額 → 振替元 → 振替先 の順に積む。
- 字は本文 14px（金額は太字 500）、補足 12px、札 11px。

## 3. 色

ライトは freee の画面から写した値（c03-deal-view の 2. の手順で読んだもの）。ダークは同じ色合いの暗い版。表示先の字の色（`--text-primary`）の明るさを見て、ダークの色に切り替える（itinerary と同じ見分け方）。表の地は、ライトは白、ダークは透明（チャットの地のまま）で細い枠線を付ける。

| 要素 | ライト（文字／地） | ダーク（文字／地） |
|---|---|---|
| 支出の札 | #DC1E32／白・線 #DC1E32 | #FF6B78／透明・線 #FF6B78 |
| 収入の札・金額のリンク | #285AC8 | 札 #7FA2F0・リンク #8FB0FF |
| 取引先のチップ | #6E0F19／#FAD2D7 | #F7C2CA／#4A1C24 |
| 品目のチップ | #004B1E／#CDEBD7 | #B4E3C3／#1B3D27 |
| メモタグのチップ | #825A0F／#FFF0D2 | #F2D296／#3E3012 |

## 4. 部品の直し方

- inlinetable と同じ（トップの README の 12.）：今の版を元に直し、新しい版の名前（`dv_vYYMMDDa.js`。同じ日の2版目は b、c…）で dealview/ に上げる。同じ名前で上げ直さない。古い版は消さない。
- 上げたら、この README の「今の版」と読み込みの1行、スキル c03-deal-view の読み込みの1行を新しい版に直す。
- 色を変えるときは、Chrome で freee の取引一覧を開いて getComputedStyle で読んでから直す（c03-deal-view の 2.）。ダークの色は、明るい画面・暗い画面の両方で見て決める。
- 列の幅や積み方を変えたら、チャット（広い画面）とスマホで崩れないかを確かめる。
